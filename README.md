## Task PropChain Connect Wallet ⛓

# Implemented with Zustand, global state with connection, permissions and show address with metamask. If metamask is not installed, display alert information to install metamask.

1. Clone the fork repository:
   ```bash
   git clone url-proyect
   ```
3. Installed new packages for the project
   ```bash
   npm install | pnpm install | npm i | pnpm i
   ```

4. Run Proyect with changes applied:
   ```bash
   pnpm run dev | npm run dev
   ```

5. If you browser installed metamask, shwo popup to connect and allow DApp to connect. ☑️
